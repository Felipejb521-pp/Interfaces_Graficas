# Introducción a GUI en Java (AWT y Swing)

Este repositorio contiene los ejercicios introductorios de maquetación e interfaces gráficas con **AWT** y **Swing**, desarrollados durante la fase de **Formación Dual** del 1.º curso del ciclo formativo de **Desarrollo de Aplicaciones Multiplataforma (DAM)**.

## Contenido

El proyecto consta de 3 formularios interactivos diseñados de forma visual y orientados a eventos básicos:

* **3 Ventanas (`.form` / `.java`):** Diseño visual de componentes y su correspondiente código de soporte en Java SE.
* **AWT & Swing:** Uso de contenedores, botones, etiquetas, campos de texto y manejo básico de eventos.

## Entorno de Desarrollo

* **IDE:** NetBeans IDE (diseñador gráfico de formularios)
* **Lenguaje:** Java SE
